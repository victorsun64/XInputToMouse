# XInputToMouse
Small program that allows XInput controller to control mouse for windows

> supported actions:
 >  - toggling mouse control if both shoulder buttons are pressed
 >  - exiting program if select and start are pressed
 >  - moving mouse with left joystick
 >  - scrolling the mousewheel with right joystick
 >  - emulating left/middle/right mouse button clicks with controller
